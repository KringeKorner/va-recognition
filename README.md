### VA-Recognition
---
The VA-Recognition repository contains the visual and audio recognition software for the ***W****ireless* ***A****lgorithmic* ***L****isten &* ***L****ook* ***E****xplorer* (W.A.L.L.E.) capstone project for Toronto Metropolitan University (*formerly Ryerson*).

## Documentation and additional resources
---
Additional resources for W.A.L.L.E. project can be found under the google drive link. The drive contains development files as well as files generated by the va-recognition software at various stages of development. 
**Google Drive**: [Wireless Algorithmic Listen & Look Explorer](https://drive.google.com/drive/folders/1Pmkm8A1rJ6AgDZ0gNAKWGZ4TtK0vQobT?usp=sharing)

The drive is organized as follows:
1. Images
   - Images contains all of the diagrams used to assist with software development, featuring architecture plans and gantt charts
2. Logs
   - Logs contains generated log files from various stages of software development. The folders contain the log files of the various systems implemented by the va-recognition software, while the isolated text files are from a proof-of-concept (*POC*) build made to demonstrate raspberry pi compatability and dual AI models operating in parallel
3. MCR
     - MCR contains the milestone table and milestone compliance reports for the duration of the project
4. MINERVA Reconstructions
     - MINERVA Reconstructions contains saves of successful visual recognition runs made by the MINERVA POC subsystem
5. Reports
     - Reports contains supplementary and final reports created during and after the active development cycle of the capstone project
